# 页面骨架

> 写页面时读。`references/template.html` 是结构范本，本文件说明布局契约与取舍理由；
> 两者冲突时以范本为准，并回头修正本文件。

## 1. 页面结构

### 1.1 结构

```text
shell
├─ 左栏
│  ├─ 章节头
│  ├─ stage
│  │  ├─ SVG 舞台
│  │  ├─ 画布内字幕
│  │  ├─ 播放层
│  │  └─ 门禁（可选）
│  └─ rack：播放 / 进度 / 章节刻度
└─ 右栏：参考资料
```

窄屏退成单栏，侧栏排在舞台之后。

### 1.2 顶部只留章节头

顶部不放常驻工具条，也不排章节胶囊行。"进行到哪一节、整门课多长"由播放器行的进度条
承担（每节一根刻度，悬停报段名）。画布上方只有章节头一块：徽章 + 标题一行，副标题
独占下一行，长句不在标题行里随机断行。

## 2. 舞台

### 2.1 尺寸契约

```css
.stage{
  position:relative;
  overflow:hidden;
}
.stage svg{
  display:block;
  width:100%;
  height:auto;
  aspect-ratio:<viewBox-width>/<viewBox-height>;
}
```

- 舞台宽度就是左栏宽度。想整体收窄就收 `.shell`，不要给舞台单独设 `max-width`，
  也不要给 SVG 单独封顶。
- 不用 `flex:1` 或 `height:100%` 把舞台拉满高度。唯一例外是全屏态：
  `.col-stage:fullscreen .stage{flex:1}`——全屏的意义就是画布尽量大。
- `viewBox` 比例由场景内容并集决定，不为"填满屏幕"制造大块空白。

### 2.2 门禁开启时的最小高度

门禁开着时给舞台一条 `min-height` 下限（范本 §②b）。视口项用 `dvh` 跟住手机地址栏
收放，不认识的浏览器由前一条 `100vh` 兜底。窄栏里按比例算出的高度装不下卡片，
`overflow:hidden` 会把它裁掉；装不下的余量由 `.gate` 自己的 `overflow:auto` 滚动
兜底。除此之外不主动拉扯舞台高度。

### 2.3 视差远景层

取景框（`clip-path="#frameClip"` 那层包装 `<g>`）里可以再放一层视差远景（范本
`#depth`）。它与 `#cam` **同级**、共用同一个世界坐标系，镜头每落一次按 `--par-far`
同向漂一小段（`stage.md` §3.3）。

放同级而非放进 `#cam`，原因有二：`#cam` 自己带 `transform` 属性值，再叠一层会互相
顶掉；同级也保证它跟着取景框一起被裁切，推近时不会越到字幕带上来。

## 3. 播放层

未开始时用画布内播放层提示开始；开始后由 `stage[data-state]` 切换到播放态。

播放层只是页面 UI，只调用 `audio.play()` / `audio.pause()`。播放器不拥有时间轴，
时间轴属于 `audio.currentTime`。

## 4. 字幕

### 4.1 DOM 契约

字幕必须长在 SVG 里：

```html
<g id="cap">
  <line ... />
  <text id="cap-text" data-courseware-caption="1"></text>
</g>
```

要求：位置固定、字号固定、画面底部保留带，文案唯一来自 `runtime.narration[].text`。

`#cap` 在 `#cam` **外面**：镜头推拉与取景框裁剪都碰不到它。它承担"念什么就显什么"，
画面怎么演都不该让字幕跟着跳。带内分隔线（范本 y=404）同时是**取景框下沿**：相机
可见区到此为止，画布内容不排到它以下（`stage.md` §3.3）。

契约钩子的 HTML 属性（`id` / `src` 等）必须带引号：检查器与导出脚本的静态解析只认
`id="…"` / `src='…'` 两种形态，裸写 `id=cap-text` 会被当成"钩子缺失"假拒。
`data-courseware-caption` 只查属性名存在，值裸写不拦。

### 4.2 派生视图

字幕带内允许两种派生视图，它们都不是第二份文案：

- **结论句色带**（范本 `#cap-hl`，写在 `#cap-text` 之前、字压在上面）：`hl:true` 那句
  沿自己的字宽划一道半透明主色。几何由 `capShow()` 从 `#cap-text` 现量。
- **句内进度细线**（范本 `#cap-prog`，在 `#cap-hl` 之后、`#cap-text` 之前）：沿当句
  字宽划一道 2px 细线，表示"这一句念到哪儿"。

两者的实现口径不同：

| 视图 | 几何 | 更新方式 |
|---|---|---|
| 色带 `#cap-hl` | 现量 `#cap-text` bbox | 补间：`x` / `width` 进 `transition` |
| 细线 `#cap-prog` | 现量 `#cap-text` bbox | 逐拍写呈现属性，**不挂 transition** |

细线不补间，因为它是 `audio.currentTime` 的读数，补间只会让它永远落后于正在念的字。
几何现量意味着桌面 17px 与小屏 26px 两套字号都不用写常数；细线走在字幕自己那一列，
左端跟着 bbox，不会压住说话人标签（`#cap-speaker` 从 x=44 起）。

`opacity:.22` 挂在色带自己身上，不参与 `#cap` 的显隐链，因此不会把字幕判成"被压暗"。
QA 读的始终是 `#cap-text` 的 `textContent` 与祖先链可见性。

### 4.3 小屏放大与取景兜底

**小屏判定只有一处**：JS `setCompact()`——宽 ≤560 或高 ≤560。手机横屏宽有 800+，
够不着宽度断点，但画布受高度限制等比缩小后小字照样糊。结果写进
`html[data-compact="1"]`，字号分档 CSS、`put()`、`camSet()` 全部只认这个开关。
导出截图模式（`__coursewareShotMode`）强制桌面渲染，放大只服务移动端真机；
旗标语义见 `runtime.md` §7。

- **字号分档**：越小的字乘得越狠（≤14 ×2、≤19 ×1.7、≤26 ×1.45、更大 ×1.3），
  动态图元在 `put()` 写属性时单点处理（`scaleFontSize()`），静态标记用 CSS 属性
  选择器同比例分档；字幕 26px。
- **兜底取景 `camSet()`**：窄屏下**没有声明取景窗**的那一步，按内容包围盒
  （`contentBox()`）等比缩放、钉在字幕带上方内容区的正中（上限 1.8×、下限 0.85×）。
  字和框同倍率，不产生框内溢出，同时修掉个别场景偏一侧的问题。桌面只走 `CAM` 表里
  声明的窗（`stage.md` §3.3），没声明就是 identity。门禁热点的圈在卡片自己的小图里，
  不受影响。

断点切换时 `lastKey=''; tick()` 把当前句按新档位重画并重取景。**调字号档位或取景
区域常数，必须逐场景截图复核。**

## 5. 播放器行

### 5.1 组成

播放器行紧贴舞台下面，常驻：

```text
▶  ⟲  🔊  [progress / chapter marks]  3/8 · 时间  1×  ⛶
```

点一下跳到该处，按住拖就是擦洗（触屏横拖同理）。`.bar` 因此要 `touch-action:none`，
这是全页唯一一处 `none`，其余触屏滚动都放行。

读数只放"第几节 + 时间"：章节名在章节头已有一处，重复进这条窄行会挤进度条，窄屏
下还会溢出。

### 5.2 进度条

进度条同时承担章节地图，不再在舞台上方另排章节导航。

- **窥探气泡**：悬停/拖动都报"第 N 节 · 标题 · 时间"（`.bar .tip`）。用 **pointer
  事件**驱动——指针捕获期间兼容 mouse 事件不可靠，`pointermove` 在悬停和拖动中都
  稳定触发。
- **跟手模式**：按下时 `.bar[data-drag]` 把填充过渡缩到 50ms，松手恢复 `--dur-fill`
  滑行到位。
- **当前章节刻度点亮**：`.tick.on`，与章节头同一个 `sceneIdxAt`，位置 cue。
- **意图升级**：指针落到条上 / 键盘聚焦 / 按下拖动时，6px 轨道升到 9px、刻度从
  12px 长到 16px、窥探气泡轻弹 7px 落定。把"现在可以拖"画在你正指着的那根条上，
  而不是在旁边再摆一个可见把手。过渡清单只给 `height` / `border-radius` 两条几何；
  `width` 属于 `--dur-fill` 那套"进度连续滑动"，混进来就是第二个时钟。填充圆角
  `inherit` 跟着轨道走；刻度用 `top:50%` + 独立 `translate` 居中，两种高度共用
  一条公式。命中区仍靠 `.bar::before` 上下各扩 7px，变厚不影响它。
- **按键下沉**：`.rack button:active{scale:.9}`，独立 `scale` 属性不碰布局，松手
  回原样——手指离开屏幕前就该知道"按到了"。

进度条是键盘可达的 slider：`role="slider"` + `tabindex="0"` 写在标记里，
`aria-valuemin/max/now` 由 JS 在 `TOTAL` 就绪后写真实值。焦点在条上时 `←/→` 微调
±1s、`Home/End` 到头/尾；方向键在本元素 `stopPropagation`，不叠加 document 层的
±8s 擦洗——细调与快擦是两种手势，不该互相打架。

### 5.3 倍速

`1×` 是倍速键，按 1 → 1.25 → 1.5 → 2 → 0.75 轮切，非 1× 时描色常亮。

画面、字幕、门禁全是 `currentTime` 的纯函数，变速只是让时钟走得快些，页面不需要
第二套逻辑；导出截图页走直接 seek，成片不受倍速影响。这是"单一时钟"白送的能力，
**有倍速需求的课件不要自己另发明**。

### 5.4 窄屏与全屏形态

窄屏（≤560px）与**全屏**下这一行改悬浮收起式：默认藏进画布下缘，点画布唤出，
再点一下立刻收回，3s 无操作只是兜底；门禁开着时唤不出。

- rack 形态只认宽度和全屏，不像字号那样认矮屏；横屏不全屏时仍常驻。
- 悬浮态 CSS 在 `≤560` 媒体块与 `.col-stage:fullscreen` 块各写一份（媒体查询无法
  共享规则体），**改一处两处都要改**。
- 窄屏（宽度 ≤560px）下这一行整体收紧（间距 / 内边距 / 读数字号）；五个控件的
  透明伪元素热区外扩与 ≤11.5px 小字提级走"页面外壳"口径，**宽 ≤560px 或高 ≤560px
  任一命中即生效**（理由同 §4.3）。竖屏手机上行下方浮出一行"转成横屏观看更清楚"
  的软提示，横屏即收。

### 5.5 全屏与静音

- **⛶ 全屏（快捷键 F）**：对整条画布列（舞台 + 播放器行）请求全屏，章节头与侧栏
  退场，播放器行切成悬浮收起式（`fullscreenchange` 里 `rackReset()` 统一换形态）；
  门禁浮在舞台内部，全屏下照常可用。不支持 `Element.requestFullscreen` 的环境
  （iOS Safari）收起该按钮。
- **🔊 静音（快捷键 M）**：只切 `audio.muted`，与 `currentTime` 无关——"单一时钟"
  只管进度，音量是独立的传输控制，门禁打开时也能静音。静音态用 `body[data-muted]`
  切换两个 SVG 图标（与全屏按钮的 `data-fs` 同一套模式），`aria-pressed` 同步。

### 5.6 门禁期间

门禁打开时播放器行只变灰（悬浮态下直接不显形），且不可绕过门禁：`pointer-events:none`
挡鼠标，`inert` 连 Tab 焦点一起挡——只有前者会留下键盘 Enter 绕过。

同一条规则也管画布内的播放层：CSS 把它压成透明时它仍在 Tab 序列里，焦点常常就停在
上面（学习者正是点它起的播），门禁 `openGate` 期间必须连它一起 `inert`，`closeGate`
还原。

## 6. 侧栏

### 6.1 内容边界

侧栏只放两类内容：

- 参考要点（可含结论式短代码行与跳转锚）；
- 少量不阻塞播放的手感实验。

侧栏内容不跟随旁白逐句高亮，也不写进证据。分层靠排版，不靠容器。

### 6.2 信息形态

编程课里一行代码顶三行文字。三种可选形态（参考实现见范本 §③ / §④）：

| 形态 | 用途 | 约束 |
|---|---|---|
| `code` | 一条结论式短代码 | 每行半角 ≤39 字符（全角 1 字按 2 半角计，上限 21 全角）不折行；`//` 开头自动降为暗色注释；留空不渲染 |
| `kv` | 两三条并列的「记法 → 结论」 | 左列等宽记法、右列结论，不套框不配判决色（✓/✗ 字形自带语义） |
| `at` | 「⇸ 看这一节 mm:ss」胶囊 | 点击 seek 到讲这个点的那节 |

实测 340px 窄栏下代码块可用宽 269px，因此 `code` 只放"一眼看懂的结论"
（`[10,9,1].sort() → [1,10,9]`），不放完整示例。

判据：**一条**结论用 `code`，**两三条并列**判决用 `kv`（如比较函数的 负/零/正
三契约）；纯文字课没有记法可对照，两者都不适用。

`at` 是侧栏与时间轴**唯一**的挂钩，且只是替用户点一下进度条：写
`audio.currentTime`，与 bar seek 同一语义（`timeupdate` 兜底重画），不改播放/暂停态、
不产证据。走带与门禁逻辑对侧栏保持只读。

### 6.3 折叠

折叠条默认合上，开合是补间不是闪现。默认合让侧栏先是一份目录（一屏数得完六条
主题），读者自己决定展开哪一条；`n.open` 只给"此刻就该看见"的那一条（范本给了第一句
要用的「默认是字符串序」），不要全开——全开就退回一长条滚动正文，折叠没有意义。

配方是四件套：`interpolate-size` + `display` 进 `transition-property` +
`allow-discrete` + `@starting-style`。少一样就退回某一边的硬跳，照抄范本，不要精简。

`title` / 正文仍是一行主题 + 一小段附注；折叠只换掉"展开与否"两个状态之间的过渡，
不改变侧栏该放什么。

### 6.4 排版分层

侧栏是一列主题行 + 1px 发丝线分隔，不要再嵌第二层圆角框（唯一例外是 `code` 块——
它是内容形态的底色，不承担层级）。340px 窄栏里多层框会把视觉重量全花在搬运结构上，
六张一模一样的小卡则让所有主题"一样重要"，等于没有排序。

层级由字号与悬挂缩进承担：标题 14px 实色、正文 13px、附注更暗；正文左边界对齐标题
文字，不对齐 emoji。悬挂缩进按 `.n-ico` 的 **21px 钉宽槽**计算（emoji 字形实测比
字号宽，15px 字号占 20.6px——拿字号当槽宽必左偏约 6px）。换 emoji 不改槽宽，字形
超宽居中溢出即可，不许回头动缩进。

分类信息同样分级：主内容以正文承接，只有附注配小字标签。给 2 个字的标签做彩色药丸
底是窄栏里最不划算的装饰——挤占字宽，又不对读者表意。留空的分类整行跳过，不渲染
"只有标签没有正文"的断行。整张卡要比背景亮一档、边框深一档，否则这一列读起来是
漂着的文字，不是一个区域。

### 6.5 随滚随显

随滚随显是装饰，不是闸门。侧栏本来就要滚着看，条目随滚随显比一次全铺开更贴合阅读
顺序，而且这条运动不归 JS 管：没有 scroll 监听、没有 IntersectionObserver、没有 rAF。
范本用 CSS 滚动驱动动画 `animation-timeline: view()` 实现。

它是全站唯一"可能整个不跑"的动效，因此边界比别处更硬：

- 整块包在 `@supports (animation-timeline: view())` 里，隐藏态只写在 keyframe 的
  `from`。不支持的浏览器（如 Firefox 正式版）整块跳过，六条要点一格不少。
- **静止态也必须全部可读**。落点写在 `cover 32%` 时，侧栏不溢出时下面三条会停在
  0.998 / 0.974 / 0.845——装饰把常驻内容留在了半透明那一格。落点取 **entry 段内**
  （`entry 0% entry 60%`）才是"滚进来的时候演，没得滚就在那儿"。
- reduced-motion 兜底写成 `ul.notes>li.note`：基础规则源序在后，朴素选择器盖不过它。

### 6.6 行首标点收边

`text-spacing-trim:trim-start` 收掉行首那半格全角标点。中文正文里全角标点即使出现在
行首也照样占满一个字盒，于是以「、（、，起头的那一行比后面的字往右缩半格，两栏读
起来是锯齿。实测 13px 档整行 −6.5px、16px 档 −8.0px，两档都恰好 0.5em；行首是汉字
则逐值不动。16px 档还会把断点往前挪一个字，省下的本来就是空白。

范本只挂在**会换行的 HTML 正文**上（`.n-txt` / `.gate .q` / `.interaction-feedback` /
`.chapter .tagline`），整块包 `@supports`。**字幕带不挂**：它单行不换行、看不见收益，
却要动 `#cap-hl` / `#cap-prog` / `--lit` 三个派生视图共用的 bbox 读数；等宽 `code`
与对照行 `.kv` 同理。

两条测量坑：块盒 `getBoundingClientRect().width` 量不到任何变化（会得到"这属性没用"
的假结论）；SVG `<text>` 上它确实生效，但按 `text-anchor` 分摊偏移。

## 7. 层叠

```text
SVG 内容 0
播放层 5
浮动卡片架 7（窄屏 / 全屏下浮到舞台底部，压在播放层上）
preGate 过渡层 8（盖住播放层，但不盖题目——它就是"题目马上出现"的 1.1 秒）
门禁 9
```

字幕是 SVG 的最后一组内容，所以属于画布的一部分。

## 8. 交付

源形态：

```text
index.html
interactive_runtime.js
audio/
```

直接把这个目录交出去即可。Courseware Studio 不自带单文件 bundler；需要单文件时交给
通用的 Artifact / Web 处理能力，不把它变成这个 skill 的基础设施。
