# 页面骨架

> 写页面时读。`references/template.html` 是最终结构范本，本文件只说明布局契约。

## 1. 页面结构

```text
shell
├─ 左栏
│  ├─ 章节头
│  ├─ stage
│  │  ├─ SVG 舞台
│  │  ├─ 画布内字幕
│  │  ├─ 播放层
│  │  └─ 门禁（可选）
│  └─ rack：播放 / 进度 / 章节刻度
└─ 右栏：参考资料
```

窄屏退成单栏，侧栏放在舞台之后。

顶部**不放常驻工具条 / 章节胶囊行**："进行到哪一节、整门课多长"由播放器行的
进度条承担（每节起点一根刻度 + 悬停报段名），画布上方只留章节头一块
（徽章 + 标题一行，副标题 tagline 独占下一行，长句不在标题行里随机断行）。

## 2. 舞台

```css
.stage{
  position:relative;
  overflow:hidden;
}
.stage svg{
  display:block;
  width:100%;
  height:auto;
  aspect-ratio:<viewBox-width>/<viewBox-height>;
}
```

不要给舞台单独设 `max-width`，不要用 `flex:1` 或 `height:100%` 把舞台拉满高度。

舞台宽度就是左栏宽度。想整体收窄，收 `.shell`，不要单独封顶 SVG。

`viewBox` 比例应该由场景内容并集决定，不要为了“填满屏幕”制造大块空白。

门禁开着时给舞台一条 `min-height` 下限（见 template.html §②b；视口项用 dvh 跟住手机
地址栏的收放，不认识 dvh 的浏览器由前一条 100vh 兜底）：窄栏里按比例算出的
高度装不下卡片，`overflow:hidden` 会把它裁掉。除此之外不要主动拉扯舞台高度。

## 3. 播放层

未开始时用画布内播放层提示用户开始；开始后由 `stage[data-state]` 切换到播放态。

播放层只是页面 UI：

```js
audio.play()
audio.pause()
```

播放器本身不拥有时间轴。

## 4. 字幕

字幕必须长在 SVG 里：

```html
<g id="cap">
  <line ... />
  <text id="cap-text" data-courseware-caption="1"></text>
</g>
```

要求：位置固定、字号固定、画面底部保留带，文案唯一来自 `runtime.narration[].text`。

契约钩子的 HTML 属性（`id` / `src` 等）必须带引号写：检查器与导出脚本的静态解析
只认 `id="…"` / `src='…'` 两种引号形态，裸写 `id=cap-text` 会被当成"钩子缺失"
假拒（`data-courseware-caption` 只查属性名存在，值裸写不拦）。

小屏是例外，两层放大叠加。**小屏判定只有一处**：JS `setCompact()`（宽 ≤560 或高
≤560——手机横屏宽有 800+，够不着宽度断点，但画布受高度限制等比缩小后小字照样糊），
结果写进 `html[data-compact="1"]`，字号分档 CSS、`mk()`、`stageFit()` 全部只认这个
开关。**导出截图模式（`__coursewareShotMode`）强制桌面画风**：视频与桌面页面永远
同一张脸，放大只服务移动端真机：

- **字号分档**：越小的字乘得越狠（≤14 ×2、≤19 ×1.7、≤26 ×1.45、更大 ×1.3），
  动态图元在 `mk()` 单点处理，静态标记用 CSS 属性选择器同比例分档；字幕 26px；
- **自适应取景 `stageFit()`**：换幕后把当前场景按内容包围盒等比缩放、钉在字幕带
  上方内容区的正中（上限 1.8×、下限 0.85×）。字和框同倍率，不产生框内溢出，
  同时修掉个别场景天生偏一侧的问题；门禁热点的圈在卡片自己的小图里，不受影响。

断点切换时 `lastKey=''; tick()` 把当前句按新档位重画并重取景。**调字号档位或取景
区域常数，必须逐场景截图复核。**

## 5. 播放器行

播放器行紧贴舞台下面：

```text
▶  ⟲  [progress / chapter marks]  3/8 · 时间  1×  ⛶
```

它常驻。进度条同时承担章节地图，不再在舞台上方另排一行章节导航。
点一下跳到该处，按住拖就是擦洗（触屏横拖同；`.bar` 因此要 `touch-action:none`，
这是全页唯一一处 `none`——其余触屏滚动都放行）。
`1×` 是倍速键（1 / 1.25 / 1.5 / 2 / 0.75 轮切，非 1× 时描色常亮）：画面、字幕、门禁
全是 `currentTime` 的纯函数，变速只是让时钟走得快些，页面不需要第二套逻辑；导出截图页
走直接 seek，成片不受倍速影响。这是"单一时钟"白送的能力——**有倍速需求的课件不要自己
另发明**，用这个轮子。
窄屏（≤560px）和**全屏**下这一行改**悬浮收起式**（全屏的意义就是让画布尽量大，不管
宽度；横屏不全屏时仍常驻——rack 形态只认宽度和全屏，不像字号那样认矮屏）：默认藏
进画布下缘，点画布唤出、**再点一下立刻收回**，3s 无操作只是兜底；
门禁开着时唤不出。悬浮态的 CSS 在 `≤560` 媒体块与 `.col-stage:fullscreen` 块各写一
份（媒体查询无法共享规则体），**改一处两处都要改**。
读数只放"第几节 + 时间"：章节名在章节头里已经有一处，重复进这条窄行会挤进度条、
窄屏下还会溢出。

门禁打开时播放器行只变灰（悬浮态下直接不显形）、不可绕过门禁（`pointer-events:none`
挡鼠标，`inert` 连 Tab 焦点一起挡——只有前者会留下键盘 Enter 绕过）。同一条规则也
管画布内的播放层：CSS 把它压成透明时它仍在 Tab 序列里，焦点常常就停在上面（学习者
正是点它起的播），门禁 `openGate` 期间必须连它一起 `inert`，`closeGate` 还原。

⛶ 是全屏按钮（快捷键 F）：对整条画布列（舞台 + 播放器行）请求全屏，章节头与侧栏
退场，播放器行随之切成上面说的悬浮收起式（`fullscreenchange` 里 `rackReset()` 统一
换形态）；门禁浮在舞台内部，全屏下照常可用。不支持 `Element.requestFullscreen` 的
环境（iOS Safari）收起该按钮。

窄屏（宽度 ≤560px）下这一行还整体收紧（间距 / 内边距 / 读数字号）；▶ ⟲ 1× ⛶ 四个
控件的透明伪元素热区外扩与 ≤11.5px 小字提级走"页面外壳"口径，
**宽 ≤560px 或高 ≤560px 任一命中即生效**（理由同 §4 小屏判定）；竖屏手机上行下方
浮出一行"转成横屏观看更清楚"的软提示，横屏即收。

## 6. 侧栏

侧栏只放：

- 参考要点；
- 少量不阻塞播放的手感实验。

侧栏内容不跟随旁白逐句高亮，也不写进证据。

## 7. 层叠

```text
SVG 内容 0
播放层 5
浮动卡片架 7（窄屏 / 全屏下浮到舞台底部，压在播放层上）
preGate 过渡层 8（盖住播放层，但不盖题目——它就是"题目马上出现"的那 1.1 秒）
门禁 9
```

字幕是 SVG 的最后一组内容，所以属于画布的一部分。

## 8. 交付

源形态：

```text
index.html
interactive_runtime.js
audio/
```

直接把这个目录交出去即可。Courseware Studio 不自带单文件 bundler；需要单文件时交给通用的 Artifact / Web 处理能力，不把它变成这个 skill 的基础设施。
